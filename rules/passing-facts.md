# Facts mentioned in passing (automem-plus)

When the user mentions a lasting fact about this project in passing, while asking for something else, save it to auto memory as you would if they had said "remember this". Examples: how CI runs, who reviews or approves changes, deploy targets, release conventions, environments, people's roles, constraints from outside the code.

Don't save what the code, git history or CLAUDE.md already show, one-off task details, or anything secret. If a note on the same thing exists, update it instead of adding another.
